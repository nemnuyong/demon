# Spider Hero 3D

Một game mini 3D lấy cảm hứng từ Spider-Man, chạy trực tiếp trên trình duyệt với Three.js.

## Chạy local

```bash
python3 -m http.server 4173
```

Mở `http://localhost:4173`.

## Điều khiển

- `WASD` / phím mũi tên: di chuyển
- `Space`: nhảy
- `Shift`: tăng tốc
- Chuột trái (giữ): bắn tơ và đu
- Nhả chuột: thả tơ
